## How to contribute

We welcome all developers to join Tech-Art's open source collaboration! Whether it's submitting bugs, proposing new features, or contributing code, we are looking forward to your participation!
- **Start contributing**: Fork our repository, submit a Pull Request, or make suggestions on the Issue page.
- **Notes**: Please make sure the code is clear, well-commented, and follows the basic structure of the project.
